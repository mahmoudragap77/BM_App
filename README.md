BM App

A simple Bank Misr-inspired Android login UI built with Kotlin and Jetpack Compose.

Features
Login screen with username and password fields
Password visibility toggle
Input validation
Language picker
Help & Contact Us link
Quick service shortcuts
Responsive Compose UI
Tech Stack
Kotlin
Jetpack Compose
Material 3
Android SDK
Purpose

This project was created for Android UI/Jetpack Compose practice, focusing on reusable composables and clean UI structure.
